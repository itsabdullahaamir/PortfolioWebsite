# src/components/ — reusable UI primitives

Parent: [`../CLAUDE.md`](../CLAUDE.md) → [`/CLAUDE.md`](../../CLAUDE.md).
Any change in this folder updates this file and the root repo map/phase
table in the same change.

Everything here is presentational/interaction plumbing. **No component in
this folder may hardcode resume copy** — content comes from
[`../data/episodes.js`](../data/CLAUDE.md) or `toastVariants.js`, passed
in as props.

## Notes for whoever builds the remaining four

- Match `Panel.jsx`'s pattern of a small `seed`-driven pure function for any per-instance visual variation — don't hand-roll random values in render (breaks on re-render, fails deterministic tests).
- **Resolved:** `MainMenu.jsx` and `TitleReveal.jsx` stayed fully independent, each with its own `onDone`/`reducedMotion` prop handoff (`MainMenu.jsx` has no `onDone` since it's the terminal beat). `src/screens/TitleScreen.jsx` owns the beat-sequencing state and swaps between the three components.
- **Superseded this batch:** the backdrop used to be duplicated Tailwind classes in both files (judged simpler when it was two lines of gradient). Once the backdrop grew into a real layered scene (`TitleBackdrop.jsx` — SVG silhouettes, vignette, halftone), duplication stopped being the simpler option: two copies could silently drift apart, directly undermining spec 4.1's "this continuity... is the actual Walking Dead structure" requirement that beats 2 and 3 be the *same* scene. `TitleBackdrop.jsx` is now a shared component both files mount; each file still owns its own text/interaction layer on top of it.
